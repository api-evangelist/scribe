# Scribe

> Scribe is an AI workflow-documentation platform (scribehow) that auto-generates step-by-step guides for any process or software. Its Search & Retrieval API provides programmatic, read-only access to an organization's knowledge base — Scribe Documents (step-by-step guides) and Knowledge Pages (long-form reference) — for integration into custom applications and AI agents. Public API access is an Enterprise-plan feature; authentication is a static API key sent in the X-API-Key header.

## APIs

- [Scribe Search & Retrieval API (OpenAPI 3.1)](https://public-api.scribehow.com/public-api/schema/download/): Read-only search, list, and retrieve over Scribe Documents and Knowledge Pages. Base URL https://public-api.scribehow.com. Operations: v1_search_documents (POST /v1/search/), v1_get_documents (GET /v1/documents/), v1_retrieve_document (GET /v1/documents/{id}/), v1_teams_list (GET /v1/teams/).
- [API Reference (ReDoc)](https://public-api.scribehow.com/schema/redoc/): Rendered reference for the Search & Retrieval API.
